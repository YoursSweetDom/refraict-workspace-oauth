RefrAIct Workspace — privacy notice

Updated: 28 September 2026. This notice describes the owner's personal Workspace integration, not other RefrAIct products.

Google data and purpose

With the owner's consent, the local MCP server uses Google APIs to retrieve and change the owner's files, documents, spreadsheets, presentations and other requested Workspace data. It uses these data to carry out the owner's instructions and display results in Antigravity.

Storage and recipients

OAuth credentials are stored on the owner's computer. Downloads, test files and local logs may also be stored there. They are not stored by this static website. Depending on Antigravity settings and the owner's instructions, retrieved information may be included in messages sent to Antigravity and its selected AI provider. Those services apply their own privacy policies and retention rules. Google processes API requests under its policies. No integration-specific encryption or automatic deletion guarantee is made.

Control and retention

The owner can revoke access through Google Account permissions and remove local credentials, logs and downloaded files. Revocation stops future authorized API access; it does not remove existing local copies or data already processed by other services. The integration is not configured to sell Google data or use it for advertising.

This website

This site contains public information only, with no application analytics, account forms or advertising. GitHub Pages may process routine technical access information under GitHub's privacy policy. No private Google data or authentication credentials belong in this site's repository.

Questions can be directed to the owner through the owner's GitHub profile.
